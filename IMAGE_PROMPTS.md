# Image prompts

Every new photo slot on the site has a placeholder image right now. To replace one:

1. Copy its prompt below into your image generator and choose the **shape** shown.
2. Save the result as a **.jpg** with the **exact file name** shown.
3. Put it in the folder shown under `public/images/`, replacing the placeholder.

The site picks up the new image by itself. Bigger than the suggested size is fine; the shape matters more than the exact pixels.

| Shape | Suggested size |
| --- | --- |
| 16:9 | 1920 × 1080 |
| 4:3 | 1600 × 1200 |
| 1:1 | 1200 × 1200 |
| 3:4 | 1200 × 1600 |
